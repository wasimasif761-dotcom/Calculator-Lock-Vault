## 🚀 Key Features

1. **Fake Calculator Frontend:**
   * Works 100% like a real calculator (`+`, `-`, `×`, `÷`, `%`, `()`, `.`, `⌫`).
   * **Secret Trigger:** Type your 4-digit PIN followed by `=` to seamlessly unlock the hidden vault.
2. **First-Time Setup Flow:**
   * Welcome privacy notice card.
   * Media & storage permission prompt.
   * Interactive PIN creation & confirmation guide.
   * Transition interstitial ad mockup with countdown timer.
3. **Media Vault:**
   * Encrypted photo, video, and file storage.
   * Android Photo Picker integration to import media without broad storage permissions.
   * Fullscreen viewer with unhide/restore and permanent deletion.
4. **Hide Apps:**
   * Stealth container to conceal apps (WhatsApp, Telegram, Messenger, Instagram, Tinder, etc.).
5. **Smart App Lock:**
   * PIN-protected app locking with simulated lock screen and numeric keypad.
6. **Privacy Web Browser:**
   * Zero-history incognito browser with bookmarks.
   * Instant "Burn & Exit" button to shred session cookies and history.
7. **Video Downloader:**
   * Multi-format download manager with real-time speed meter and direct save to vault.
8. **Private Notes:**
   * Categorized confidential notes (Diaries, Passwords, Secrets, Contacts, Bank & Finance).
9. **3-Line Navigation Drawer:**
   * Accessible via the `☰` hamburger icon.
10. **Google Account & Cloud Backup:**
    * Account linking, simulated Google Drive backup sync, and sync-now trigger.
11. **Feedback & Rating System:**
    * In-app 5-star rating with direct WhatsApp and Email intent triggers.

## 📲 How to Download & Install the APK

1. Go to the **Actions** tab on this GitHub repository.
2. Select the latest **"Build Android APK"** run.
3. Scroll down to **Artifacts** and click **Calculator-Lock-v1.0.0-APK** to download the `app-debug.apk`.
4. Alternatively, check the **Releases** tab on the right side of the repository to download the release asset directly onto your Android device!
